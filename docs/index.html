PGCS: Physical Law Embedded Generative Cloud Synthesis in Remote Sensing Images

IEEE Transactions on Geoscience and Remote Sensing · 2025

Liying Xu, Huifang Li, Huanfeng Shen, Mingyang Lei, Tao Jiang

School of Resource and Environmental Sciences, Wuhan University

Paper ↗ Code ↗ Software ↓

Abstract

Data quantity and quality are both critical for information extraction and analyzation in remote sensing. However, the current remote sensing datasets often fail to meet these two requirements, for which cloud is a primary factor degrading the data quantity and quality. This limitation affects the precision of results in remote sensing application, particularly those derived from data-driven techniques. In this paper, a physical law embedded generative cloud synthesis method (PGCS) is proposed to generate diverse realistic cloud images to enhance real data and promote the development of algorithms for subsequent tasks, such as cloud correction, cloud detection, and data augmentation for classification, recognition, and segmentation. The PGCS method involves two key phases: spatial synthesis and spectral synthesis. In the spatial synthesis phase, a style-based generative adversarial network is utilized to simulate the spatial characteristics, generating an infinite number of single-channel clouds. In the spectral synthesis phase, the atmospheric scattering law is embedded through a local statistics and global fitting method, converting the single-channel clouds into multi-spectral clouds. The experimental results demonstrate that PGCS achieves a high accuracy in both phases and performs better than three other existing cloud synthesis methods. Two cloud correction methods are developed from PGCS and exhibits a superior performance compared to state-of-the-art methods in the cloud correction task. Furthermore, the application of PGCS with data from various sensors was investigated and successfully extended.

Method

Spatial synthesis. Landsat 8/9 cirrus-band observations are selected because this band captures cloud structure with little surface interference. After radiometric calibration, cropping, and removal of nearly cloud-free patches, the data are used to train StyleGAN. Random seeds then produce spatially varied single-channel cloud radiance; thresholding and linear stretching control the simulated cloud thickness.

Spectral synthesis. The single-channel output is treated as reference cloud radiance at 1.375 µm. PGCS estimates the relationship between this radiance and the wavelength-dependent atmospheric scattering parameter using local statistics followed by a global fit. The fitted scattering law converts the reference cloud into radiance for each target band, while channel offsets simulate the parallax observed between spectral bands.

WINDOWS DESKTOP APP

PGCS software

A local interface for preparing cloud simulations from multispectral imagery. Choose a sensor, supply the required images, and run one of three workflows:

Single Scene Masking
Generate one synthetic cloudy TIFF from a cloud-free multispectral scene.
Paired Dataset Construction
Crop scenes into aligned cloudy, cloud-free, and cloud-only TIFF tiles.
Designated Simulation
Use a supplied cirrus-band image as the cloud source for a designated simulation.
